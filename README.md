# La Dulcería 🎃

Página web de una sola página para **La Dulcería**, un negocio de comida rápida con temática de Halloween. Incluye hamburguesas, panes con pollo, batidos y acompañamientos.

## Publicar en GitHub Pages

1. Sube `index.html` a la raíz del repositorio.
2. Abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Elige la rama `main` y la carpeta `/ (root)`.
5. Pulsa **Save**. GitHub mostrará el enlace de la página en esa sección.

## Pedidos por WhatsApp

Los botones de los productos preparan un mensaje con el nombre del producto. El botón flotante permite enviar una consulta general.

El número de ejemplo configurado es `123456789`. Antes de publicar, reemplázalo en `index.html` por el número completo con código de país, sin el signo `+` ni espacios, tanto en `WHATSAPP_NUMBER` como en los enlaces `wa.me`.

## Personalizar antes de publicar

- Actualiza precios y descripciones con los datos reales del negocio.
- Confirma el horario: el indicador de abierto usa como ejemplo todos los días de 5:00 p. m. a 11:00 p. m.
- Cambia el teléfono, la ubicación y los enlaces de redes sociales.
- Sustituye las imágenes de Unsplash por fotografías propias, si están disponibles.
